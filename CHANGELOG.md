[CVE-2026-120869](https://www.cve.org/CVERecord?id=CVE-2026-120869) is the Console login bypass. The bulletin scores it 9.4 and says adjacent; the CVE record scores it 9.3 and says network. Red Hat's November 12 solution says any valid Quay account can still install a key, and resetting passwords or robot tokens does not revoke one already installed. - **Windows Shell:** Update Microsoft Edge to [154.0.4258.62 or later](black-october/details/windows-shell.md#remediation). Microsoft's record, updated November 10, names that build for [CVE-2026-96951](https://www.cve.org/CVERecord?id=CVE-2026-96951). The October Windows updates are unchanged.
- **Lenovo XClarity Controller 3:** On a ThinkSystem v4 whose firmware is (2.51) IHX432Y through (2.56) IHX436K, [move off that build](black-october/details/lenovo-xcc.md#remediation). Lenovo names no fixed build and says those versions are no longer available for download. Change the root password after any reset. It is not in KEV.
- **GoAhead on Windows:** The [upgrade](black-october/details/goahead-tls.md#remediation) is still 6.1.1, and it now also fixes [CVE-2026-121706](https://www.cve.org/CVERecord?id=CVE-2026-121706), which GitHub rates CVSS 3.1 8.1. It is not in KEV.
